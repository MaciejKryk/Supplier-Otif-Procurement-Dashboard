# Supplier Performance Dashboard

Power BI dashboard analyzing supplier OTIF performance.

## Features
- OTIF KPI tracking
- Top N supplier analysis
- Best/Worst supplier cards
- Supplier ranking
- Top suppliers vs remaining suppliers comparison
- Monthly OTIF trend analysis
- Dynamic slicers and filtering

## Tools Used
- Power BI
- DAX
- Power Query

## Business Use Case
Dashboard designed for procurement and supply chain performance monitoring.
